# Hurricane Relief System

The Hurricane Relief System is an application designed to help people prepare for hurricanes and request assistance during and after a storm. Users can access localized preparation guides, locate shelters, submit medical or supply relief requests, view affected locations, and receive information about nearby resources and road conditions. Volunteers and administrators can access and manage relief requests to help coordinate emergency assistance.
